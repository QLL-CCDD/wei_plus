# wei_plus：卫戍协议旧版

基于 [sganggs/Stronghold-Protocol](https://github.com/sganggs/Stronghold-Protocol) v0.1.0。当前版数据保留，旧版使用独立的 `data/legacy`。这是一套历史规则模式，仍使用同人项目的战斗引擎和修复；不会重现官方客户端的程序缺陷。

## 启动与切换

Node.js 22/24：运行 `npm run start:plus`，自动安装依赖、下载素材并启动两个版本。Windows 可直接双击根目录 `开始游戏.bat`，macOS / Linux 可运行 `bash scripts/start.sh`。旧版数据已提供，首次安装不需要重建。

- 当前版：<http://localhost:3000>。
- 旧版：<http://localhost:3001>。
- 登录页和大厅提供切换按钮。版本之间的房间独立；联机时分享该版本的邀请链接。
- 旧版卡池 115 名、策略 40 个，难度为标准、险境、绝境。新增的铃兰、杰西卡、缪尔赛思、芬策略保留，其余 36 个策略使用更新前的效果。
- Windows 本机整合安装可使用 `scripts/manage-versions.ps1 -Action Start -Ruleset legacy -OpenBrowser`。该脚本优先使用整合包旁边的便携 Node.js，找不到时使用系统安装的 Node.js。
- 局域网使用开服电脑的实际 IPv4 地址，分别访问 3000/3001 端口。所有玩家连接同一台服务器和同一个版本；localhost 页面复制的邀请优先使用局域网地址。Windows 可先运行 `scripts/repair-local-network.ps1` 只读诊断，再由用户在管理员 PowerShell 中加 `-Apply` 放行两个端口，并从匹配的 TCP 阻止规则中去除游戏端口、保留其他端口限制，来源限制为 LocalSubnet，修改前自动备份。
- 更新后先停止服务再启动。启动器不会复用原版、其他目录或旧代码服务；端口占用时请停止原服务或换端口。公网代理的两个版本分别配置入口：双版启动器使用 `SP_CURRENT_ALTERNATE_URL` 指向旧版、`SP_LEGACY_ALTERNATE_URL` 指向当前版；单服务器使用 `SP_ALTERNATE_URL` 设置另一版本的网址。

## 其他规则调整

- 陈策略从仅高台生效改为全体生效；旧版恢复高台限制。
- 余策略初始生命 32 → 27；旧版使用 32。
- 马克维茨策略随商业包装方案调整，普通装备销售门槛 7 → 8，进阶 6 → 7；旧版采用 7/6。
- 奇迹的基础免费刷新概率 25% → 18%，层数系数不变；资金奖励 50 层/10 资金 → 100 层/20 资金。
- 投资人三次触发门槛 70 → 100 层；旧版使用 70。
- 远见在历史表中有两个独立折扣：80 层远见干员减 1，150 层所有干员再减 1；更新后 150 层效果替换先前折扣。旧版实现历史叠加，新版保留原项目的替换逻辑。
- 奥术法阵新增 5 秒沉默；旧版没有新增的沉默效果。
- 终极模拟在 3 月 27 日新增，旧版入口不开放。

## 实现与验证

服务器和浏览器战斗代码均有进程级数据缓存，因而每个版本运行在独立 Node.js 进程中，共享代码与美术文件。切换会重新载入页面；不会在正在进行的同一局中换规则。

原有 2,893 项测试中，2,883 项首次通过、8 项浏览器 E2E 按原配置跳过，2 项计时基准在并发运行时超限，单独重跑均通过（0.207/0.427 ms 每 tick）。所有功能断言通过。新增验证覆盖：旧版卡池和阶位、策略保留、旧版陈伤害限制、经济里程碑、230 个普通/精锐干员的真实战斗、已安装素材文件、两个服务器的 HTTP 数据和 WebSocket 房间及 AI 隔离。修改后的相关回归亦通过。

文件完整和模拟测试不能穷尽所有对局组合；8 项浏览器 E2E 未运行。实际浏览器中检查了旧版入口、难度、调配列表和恢复干员的立绘显示。
